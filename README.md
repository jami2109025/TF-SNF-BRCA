# TF-SNF-BRCA

Analysis code for the undergraduate project report
**"Evaluating the Effect of Transcription-Factor Activity in Expression-Based
Breast Cancer Subtyping"**

Department of Computer Science and Mathematics, Bangladesh Agricultural
University, Mymensingh.

## What this study does

Gene expression is fused with an inferred transcription-factor (TF) activity
view using Similarity Network Fusion, and the added value of the second view is
measured against an expression-only baseline on two endpoints: agreement with
PAM50 in TCGA-BRCA (circular), and age- and ER-adjusted prognostic
discrimination of overall survival in METABRIC (primary, non-circular). Every
comparison is adjudicated by equivalence testing against a smallest effect size
of interest fixed before the results were seen, and reported alongside the
minimum difference the design could detect.

## Data

No patient data are included in this repository.

| Cohort | Source | Access |
|---|---|---|
| TCGA-BRCA | Genomic Data Commons, Data Release 45.0 | retrieved by `scripts/01_download_tcga.R` via `TCGAbiolinks` |
| METABRIC | cBioPortal, study `brca_metabric` | download separately; place under `data/raw/` |

Running `run_all.R` recreates `data/` from these public sources.

## Repository layout

```
scripts/     numbered analysis scripts, run in order
R/           shared helper functions
run_all.R    driver that runs the full pipeline
renv.lock    exact package environment
MANIFEST.txt frozen external resources with MD5 checksums
logs/        run logs and per-script session information
results/     figures and tables produced by the scripts
```

## Reproducing the analysis

```r
install.packages("renv")
renv::restore()      # installs the exact package versions
source("run_all.R")  # runs every script in order
```

Scripts write their outputs to `results/` and log their own session
information. Every figure and table in the report is generated by these
scripts; no value was transcribed by hand.

## External resources

CollecTRI, DoRothEA, the MSigDB Hallmark and Reactome collections, and the
resolved Ensembl-to-symbol map were frozen at the versions that produced these
results. `MANIFEST.txt` records the MD5 checksum, row and column counts, source
package and package version of each.
